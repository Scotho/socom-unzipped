Unzipped Project Map Viewer dev build

Not a port and not emulation. No game code runs. The disc's own data — geometry, textures, scene graph, lighting, fog — is read and drawn again in TypeScript, so it is a reading of the game and a reading can be wrong.

Known to differ: lighting and fog are approximations, transparency can sort wrongly, some skies and textures are missing, and there is no game — just the world.

A spin-off of SOCOM Unzipped, the actual port. s2u.scotho.com →

options
lighting (the map's own rig, trimmed)

Three directional lights and an ambient, read from the map's own GlobalLighting record — the same numbers the game hands VU1. The ambient slider is a trim. The exposure is not: the rig on its own comes out about eight times too dark against the PS2 capture, and 8.00× is that unexplained factor, so 1.00× shows the bare model.
