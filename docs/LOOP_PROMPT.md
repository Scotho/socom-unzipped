# The loop -- a pointer (SOCOM Unzipped)

This file was the loop's procedure: one iteration for whoever is the controller (steps 1-7, delegation, the sprint
close, the acceptance bar, the lock protocol). On 2026-09-26 (Sprint 14 Task I2) it moved into four project skills
under `.claude/skills/`, each a `SKILL.md` the harness loads by name:

- `loop-iteration` -- every loop firing, the steps in order, delegation, the acceptance bar.
- `agent-worktree` -- create, brief, review, merge and remove an agent's worktree.
- `run-gate` -- a build, a game run or the gate under the lock, and its record.
- `sprint-close` -- the documentation and known-issue reviews, the PR, the tag, the next sprint named.

The text as it stood is archived verbatim: `docs/archive/LOOP_PROMPT-to-2026-09-26.md`. A "LOOP_PROMPT step N",
"Every iteration" or "Lock protocol" cited before that day means the archive; the lock's rules are
`scripts/loop_lock.sh`'s header.

State lives in CURRENT_SPRINT, KNOWN, HANDOFF.
