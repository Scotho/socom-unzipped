**Goal:** the eight recurring rules become hooks and tests, the procedures become skills, four hand-maintained pages
become generated, and the host stops corrupting measurements.

**Architecture:** every guard is a small Python module under `tools_py/hooks/` or `tools_py/` with a planted-defect
unittest, wired by a tracked `.claude/settings.json` (hooks) or a tracked `.claude/agents/*.md` (roles); every
generator is `python -m tools_py.<name>` with `--check`, held to its source by a test, registered class G in
`docs/DOC_MAINTENANCE.md`; every document that shrinks is archived verbatim first.

**Tech Stack:** Python 3 unittest (no pytest — `test_test_hygiene.py` refuses it), Git Bash via
`tools_py/tests/shell.BASH`, Claude Code hooks (PreToolUse, SessionEnd, Stop; JSON on stdin, exit 2 refuses), git
hooks via `core.hooksPath scripts/hooks`, the existing `docmaint`, `issues`, `loop_lock.sh`, `run_detached.sh`.

## Global Constraints

- **Order:** G, I, W, D, S, E, M (D1). An infrastructure sprint by the owner's word of 2026-09-26; a task out of order
  needs a ruling that says what it jumped and why.
- **No feature work.** A runtime, renderer, audio or network change found necessary becomes a backlog issue, not a task.
- **A failing test first**, unittest only; RED and GREEN pasted into the Log; **every guard fired once against a
  planted violation** before it is called done (the docmaint `PlantedDefectsTest` pattern).
- **The lock:** one build or launch at a time through `scripts/loop_lock.sh run` / `run_detached.sh`; nearly every task
  here is lock-free; the lock-bound ones (W1's slow run, E2's captures, E3's red run, the close chain) run at night,
  one at a time. At most two C++-building agents at once, and W1 makes the queue enforce it.
- **Commit with an explicit pathspec**, subject `type(scope): what and why` under 120 characters once S2 lands, the
  trailer, the leak check in the hooks; never `--no-verify`; push `origin sprint-14`; `gh run list --commit` after
  a code push.
- **Every claim names its artefact;** a "merged as vX" names a tag that exists; the ceilings hold and are never raised.
- **Archive before you shrink:** a document reduced by this sprint is copied verbatim to `docs/archive/` with a banner
  and a registry row in the same commit.
- **Rulings from the global counter only** (D5); each moved default gets one at the open; no `S14-R` names.
- **Reviews:** every task by a fresh agent that did not write it (`.claude/agents/reviewer.md`), findings
  `file:line`, fix rounds to a clean re-review; diffs under `.superpowers/sdd/2026-09-26-sprint-14/` (git-ignored).
- **Nothing that is the owner's** is performed; O rows gain a line, never an act.
- **No cloud session.** Every task runs on this machine in an agent worktree (`scripts/agent_worktree.sh`); a read
  that needs only `gh` and the tree (X1) is host work too and runs only when the queue is empty of build tickets.

## Task G1: the Bash PreToolUse hook

**Files:** create `tools_py/hooks/__init__.py`, `tools_py/hooks/pretool.py`, `scripts/hooks/claude_pretool.sh`,
`.claude/settings.json`, `tools_py/tests/test_hooks.py`; modify `docs/DEVELOPING.md` (a "Guards" section).

**Interfaces:** `pretool.decide(tool_name: str, tool_input: dict, cwd: str, is_worktree: bool) -> tuple[int, str]`
returns `(0, "")` or `(2, "<rule>: <sentence>; home: <file or script>")`. `pretool.main()` reads the JSON Claude Code
gives on stdin (`tool_name`, `tool_input`, `cwd`), computes `is_worktree` as `git rev-parse --git-dir` differing from
`--git-common-dir`, prints the sentence on stderr and exits with the code. Later tasks (G2) add tool names to the
same module.

- [ ] **Step 1:** the failing tests, one planted command per rule and one allowed neighbour each, in
  `tools_py/tests/test_hooks.py` (`class PretoolPlantedTest(unittest.TestCase)`):

```python
CASES = [  # (command, is_worktree, expect_exit)
    ("git add -A", False, 2), ("git add -- docs/KNOWN.md", False, 0),
    ("git add .", False, 2), ("git add -u", False, 2),
    ("git commit -m 'x'", False, 2), ("git commit --no-edit", False, 2),   # a bare commit takes the shared index
    ("git commit -a -m 'x'", False, 2), ("git commit --all -m 'x'", False, 2),
    ("git add", False, 2), ("git add --all", False, 2), ("git add docs/research/70-new.md", False, 0),
    ("git commit -m 'x' -- docs/KNOWN.md", False, 0),
    # merge_in_progress=True (MERGE_HEAD exists): git refuses a partial commit, so a bare commit is allowed
    # -- decide(..., merge_in_progress=True) for "git commit -m 'x'" and "git commit --no-edit" -> 0
    ("git commit --no-verify -m 'x' -- a", False, 2), ("git push --no-verify", False, 2),
    ("git push origin sprint-14", True, 2), ("git push origin sprint-14", False, 0),
    ("git config remote.origin.pushurl x", True, 2), ("git config --worktree remote.origin.pushurl x", True, 0),
    ("git config --get user.name", True, 0), ("git config user.name x", False, 0),
    ("git worktree remove --force C:/projects/wt-x", False, 2),
    ("bash scripts/agent_worktree.sh remove wt-x", False, 0),
    ("bash scripts/loop_lock.sh take", False, 2), ("bash scripts/loop_lock.sh release", False, 2),
    ("bash scripts/loop_lock.sh check", False, 0), ("bash scripts/loop_lock.sh run -- ./build.sh runtime", False, 0),
]
def test_each_planted_command(self):
    for cmd, wt, want in CASES:
        code, why = pretool.decide("Bash", {"command": cmd}, "C:/projects/socom_pc", wt)
        self.assertEqual(code, want, (cmd, why))
        if want == 2: self.assertIn("home:", why)
```
