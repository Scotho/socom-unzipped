# Sprint 12 Implementation Plan — "the readable image"

> **For agentic workers:** this plan runs in the cloud session that owns Sprint 12 (the handoff
> `docs/superpowers/plans/2026-09-24-sprint-12-cloud-handoff.md`, §5–§6 are the procedure). Steps use checkbox
> (`- [ ]`) syntax for tracking. Bounded mechanical halves go to Opus sub-agents with an exact brief and a
> verification command; the controller keeps the spec, the plan, the rulings and every review.

**Goal:** Every name the project can prove is in the generated code in readable form, with its reason recorded
beside it, and the renamed tree builds and passes the r0001 gate 3/3 with PINS MATCH. Then the levers that reach
past today's 485 names — vtable slots through RTTI, BinDiff as a second signal, the demo's types with the layout-age
caveat, the toml's 656 stub names — each as a proposals file under a rule stated in code, each applied through the
same applier, each proven at a local build window.

**Architecture:** One applier (`tools_py/apply_names.py`) is the only thing that writes `recomp/socom2_ghidra.csv`'s
`Name` column, and it cannot write a name without writing its sidecar row (`recomp/socom2_names.csv`); every proposals
file (Task 7's, 7b's, 7c's, the toml-stub pass, a BinDiff-confirmed pass) is a separate input under its own acceptance
rule, in code, with the rule repeated in the file's `#` header. `carry_names` carries the sidecar to r0004 with the
name. The proof half of every applied rename (recomp, runtime, gate) is the local controller's, batched at the owner's
build windows in a worktree of `sprint-12`; the code half never becomes DONE on the cloud's word.

**Tech Stack:** Python 3 (`unittest` under `tools_py/tests`, no disc, synthetic images), the recompiler's TOML and
CSV, Ghidra 11.x headless + BinExport + BinDiff 8 and `ccc` installed under `/home/user/tools/` in the cloud
environment (not the repository), GitHub Actions (Linux only for `sprint-12` pushes).

**Spec:** `docs/superpowers/specs/2026-09-24-sprint-12-the-readable-image-design.md`. Seed rulings R257–R263 in
`docs/superpowers/plans/2026-09-23-sprint-11.md`; the handoff's ratification block (§1) amends this plan wherever it
speaks.

  tools_py/tests -t .` is the ring (its bar is `OK`; `docs/DEVELOPING.md` owns the count).

  the hooks (`bash scripts/install_hooks.sh` done; never `--no-verify`).

  re-review; diffs under `.superpowers/sdd/2026-09-24-sprint-12/` (git-ignored working memory).
